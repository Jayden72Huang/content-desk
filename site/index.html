你可能还想知道。

需要会写代码吗？

日常搭模板、编辑文章和检查内容都在界面里完成。当前源码版首次安装需要按指南运行几条命令，Agent CLI 也需要单独安装并登录。后续可以直接在本机浏览器使用。

和直接用 AI 聊天写文章有什么不同？

Content Desk 把一次对话变成可复用的内容流程：模块能保存，结构能成为模板，文章能继续排版、检查和同步草稿。下一期沿用已经设计好的结构与样式。

免费版能一直用吗？AI 费用怎么算？

Community 使用 MIT 开源许可证，软件永久免费。Codex 或 Claude Code 使用你自己的账号；模型服务商的订阅或调用费用另行计算。账号与供应商服务状态会影响生成能力。

我的文章会被上传吗？

文章和编辑记录默认保存在本机。你调用 Agent 时，输入的写作要求与选择的模板由对应 CLI 发送给模型服务商；你主动同步公众号草稿时，图文发送到微信。备份文件也应由你妥善保管。

可以直接发布到微信公众号吗？

目前只同步到草稿箱，不自动正式发布。需要配置你自己的公众号接口凭据与 IP 白名单，检查保存当前版本后再同步。实际发布在微信后台由你确认。
