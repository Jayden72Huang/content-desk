# macOS 开发构建

`bun run build:mac` 在本机使用 Xcode Swift 编译器构建 AppKit + WKWebView 宿主，
输出 `dist/macos/Content Desk.app`。最低 macOS 13；架构与运行构建的 Bun 一致。
内置当前 Bun 和依赖，用户仍需另行安装、登录自己的 Codex / Claude Code CLI。

这是开发构建，不是已通过验收的正式桌面发行包：
- 当前使用 ad-hoc 本地签名；未使用公司证书，未 Apple 公证。
- Swift 编译和本地签名构建通过。
- 此前启动已验证配套服务 health，原生窗口自动化工具无法绑定窗口。
- 下载保存对话框、文件选择、原生关闭与信号退出的实际交互验收仍待完成。
- 正式分发前补齐捆绑 Bun 的完整第三方版权通知，并验证开发者签名、公证、下载后首次启动。

服务只监听本机 8877，工作区为 `~/.content-desk`，日志为该目录的 `desktop.log`。
启动握手校验实例 ID，避免误连同端口的其他服务。关闭最后一个窗口或退出应用时终止服务。
开发构建不读取或复制原公众号工作台的数据与配置。

不得通过关闭系统安全保护来替代正式签名和首次启动验收。
