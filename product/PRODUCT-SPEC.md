# Content Desk 产品化规格

状态：实施草案；待确认产品名、首发形态、付费方式。2026-10-09。

## 产品目标

高效和 DIY 的本地内容工作台。用户自带 Coding Agent CLI 及模型账号，生成可复用模块、内容模板与文章，在同一工作台检查编辑并同步公众号草稿。官网提供介绍、开源下载、Pro 权益与购买入口。

完成标准包含真实可访问官网、独立可安装发行包、公开源码、可验证的本地 Agent 生成闭环及付费权益交付，不能以静态原型或模拟成功替代。

## 用户流程

安装/启动 → 选择工作目录 → 检测 Codex/Claude CLI → 建立系列 → 选择或 DIY 模块 → 组合内容模板 → 输入选题与参考材料 → Agent 生成预览 → 人工接受 → 编辑/审核 → 同步草稿并回读。

内容模板与视觉模板分离：内容模板定义目标读者、语气、结构、段落约束、来源要求和配图计划；视觉模板定义颜色、字体、间距与模块样式。已有独立模板示例保留，不复制进正式文章。

## 免费开源版 Community

- 本地系列、文章、图片、版本、导入导出和现有微信公众号草稿同步。
- 不限本地文章、系列及自建模板；不以删除或锁定已有数据逼迫升级。
- 模块库：标题、导语、正文、小标题、引用、列表、图片、来源、署名。
- 模块组合、排序、开关、字段编辑，内容模板与视觉模板保存。
- Codex 与 Claude Code 本地适配；单任务生成、取消、日志、失败反馈。
- CLI 自动化接口、JSON schema、示例工作流及基础模板。
- 用户自行支付模型/CLI费用；不宣称附送无限 AI。
- 建议采用 MIT；只有权属明确的产品代码/示例进入独立开源库，具体许可证在公开前定稿。

## Pro 商业版

- 批量选题与任务队列、定时工作流、失败恢复与运行历史。
- 多品牌/多公众号工作区，独立风格与发布配置。
- 高级模板包、封面与配图布局包、模板变量和条件模块。
- 跨文章批量检查、版本对比、素材复用、批量导出。
- 签名安装包、便捷更新、优先支持与持续新增模板权益。
- 本地买断优先的待确认方案：授权明确包含设备数、更新期限和到期后使用权；云备份、团队协作等持续成本另计。价格未定，不上线虚构支付按钮。
- Pro 专有实现独立于 Community；不把前端布尔开关当成授权机制。

## Agent 集成协议

1. 检测已安装程序及版本，只运行用户选择的 CLI。
2. 使用参数数组启动进程，不把用户提示拼接为 shell 命令。
3. 每个任务独立工作目录与输入快照；凭据、私人文章库与全项目源码不默认加入提示。
4. 输入包含 task 类型（module/template/article）、schemaVersion、选题、已授权资料、模板引用。
5. 输出为结构化 JSON，校验类型、长度、模块白名单、资源引用；不执行 Agent 返回的 JS/HTML 脚本。
6. 输出先保存为待接受产物；用户接受后才创建文章/模板版本，不覆盖手动修改，不自动发布。
7. 进程退出码、JSON 校验、导入和预览各自记录；退出码 0 不等同于内容已生成。
8. 取消、超时、重启中断都有明确终态；拒绝无沙箱/跳过权限默认选项。
9. 本地 API 只监听 loopback，Host/Origin/CSRF检查保留；浏览器不持有公众号密钥。

## 当前证据和缺口

已验证：Bun 工作台构建；21 项核心测试；文件版本库、模板设计与微信草稿回读逻辑；本机存在 Codex 和 Claude CLI，help 支持非交互及 schema 输出。

未验证：CLI 登录和一次真实生成；干净环境安装；通用品牌初始化；模块 schema；Pro 授权；收款渠道；在线官网；桌面签名与公证。

现有 server 默认引用个人日志路径，品牌文案和资源绑定 Jayden，项目位于私人 HackerTrip monorepo。产品化必须移除个人默认路径，用用户数据目录与通用初始示例；不公开 .local-data、公众号配置、文章备份和无授权品牌素材。

## 分阶段交付及验收

1. 独立产品基线：提取明确文件清单，通用品牌与配置，保留原工作台可运行；干净临时目录安装/构建/启动检查。
2. DIY：版本化 module/template/article schema、模块库、组合编辑与预览；导出导入一致，示例不污染文章。
3. Agent：CLI检测、任务执行和产物接受；真实生成模块、模板、文章各一例，失败/取消不产生假成功。
4. 分版：Community 完整闭环；Pro 权益表与可交付功能对齐，授权安装/验证和备份恢复实测。
5. 上线：独立开源库与许可证、官网、可下载发行包、安装指南、第三方声明；外部 URL 和下载哈希回读验证。
6. 付费：产品、价格、支付渠道、回调验签、幂等发放与退款/撤销流程；沙箱验证标为沙箱，真实收款能力单独核验。

## 本轮实施顺序

先完成独立基线与数据协议，不在当前正式文章库上跑生成测试。形态与命名确认后落地 DIY 界面、CLI 执行器和官网。发布之前提供具体源码/素材清单与权益页，避免私人 monorepo 被整体公开。
